Orientation

Nature

No es una UI comercial. Es una interfaz archivística: estructura, control y contención. El claustro es un vacío central. Las habitaciones se visitan como áreas del archivo.

How to move

  • Desktop: arrastra para rotar / explorar con precisión.
  • Mobile: con sensores activados, tu orientación define el movimiento (en las páginas destino).
  • Si el permiso está bloqueado, puedes entrar igual y reintentar después.
Structure over decoration. Precision over effect.

Initialize protocol

Initialize solicita permiso de orientación (especialmente en iOS). Si el permiso ya está concedido, entra directamente y marca el sistema como listo para autoinicio en la página de destino.
